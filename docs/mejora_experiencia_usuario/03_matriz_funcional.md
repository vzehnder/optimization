# Matriz de conservación funcional

Esta matriz es el contrato de alcance del plan. «Conservar» significa que el usuario autorizado puede completar la tarea y obtener el mismo significado de datos, aunque cambien etiquetas o ubicación. Antes de retirar una sección antigua, demostrar su reemplazo por UI o API pública y registrar la evidencia de la fila.

Las rutas indicadas omiten el prefijo `/react`. Los nombres de pruebas son referencias a cobertura existente, no resultados de una ejecución completa realizada en esta revisión.

## Registro para cada PR

En la descripción de cada PR listar las filas afectadas, el enlace/acción para acceder a cada capacidad después del cambio y la evidencia de ejecución. No marcar una fila conservada solo porque su endpoint existe si antes había una acción visible y ahora desapareció. Tampoco añadir pantallas para todas las APIs administrativas como requisito de paridad: conservar su superficie actual basta.

Mantener la eliminación de proyectos como excepción explícita al historial inmutable definida en el ADR TS7-024. «Sin pérdida funcional» no autoriza a relajar permisos o confirmaciones de impacto.
